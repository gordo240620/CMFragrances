# CM Fragrances

## Descripción

CM Fragrances es un sistema web para la venta de perfumes y decants, desarrollado como proyecto final de la materia Desarrollo Web Integral.

El sistema permitirá a los clientes registrarse, iniciar sesión, explorar el catálogo de perfumes, agregar productos al carrito, realizar compras y consultar su historial de pedidos.

Por otra parte, el administrador podrá gestionar el catálogo de perfumes, usuarios y pedidos mediante un panel de administración.
